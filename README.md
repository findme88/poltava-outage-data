# Графіки відключень Полтаваобленерго

Відкритий, неофіційний JSON із графіками на сьогодні та завтра для всіх 12 підчерг.
Джерело: [офіційний сайт АТ «Полтаваобленерго»](https://www.poe.pl.ua/).
Дані збираються незалежно від Telegram-бота та домашнього комп'ютера.

## Готовий JSON

**[Завантажити Poltavaoblenergo.json](https://raw.githubusercontent.com/findme88/poltava-outage-data/main/data/Poltavaoblenergo.json)**


Реєстрація, API-ключі та оплата для читання не потрібні.

## Оновлення та обмеження

- GitHub Actions налаштований на перевірку кожні 5 хвилин. Це розклад запусків,
  а не гарантія інтервалу: GitHub може затримувати або пропускати запуски.
- JSON публікується одразу після виявлених змін. Якщо графіки незмінні,
  час успішної перевірки записується приблизно раз на годину.
- Використовується стандартний безкоштовний runner публічного репозиторію,
  без платних runner-ів, артефактів або додаткового сервера.
- Спочатку запит іде безпосередньо до офіційного сайту. У разі мережевої помилки
  використовуються публічні українські проксі. HTTPS-сертифікат офіційного сайту
  завжди перевіряється; їхня геолокація та доступність не гарантуються.
- Неповна таблиця, невідомий стан або дата не вгадуються і не заповнюються зеленим.
  При повній помилці файл залишається незмінним, а запуск позначається невдалим.
- Якщо підтверджено лише один день, раніше підтверджений інший день може
  залишитися з `fresh: false` та незмінним `verifiedAt`.
- Перевіряйте дати та `metadata.days[дата].verifiedAt`. `lastUpdated` стосується
  найновішої успішної перевірки, а не обов'язково кожного дня у файлі.
- Не використовуйте ці дані як гарантію фактичного електропостачання.
  Пріоритет мають офіційні повідомлення оператора.

Статус запусків: [Actions](https://github.com/findme88/poltava-outage-data/actions).
Власник репозиторію може також запустити workflow вручну. Опція `force_publish`
примусово записує файл, але лише після успішної перевірки офіційного джерела.

## Сумісність зі старим джерелом

Збережена структура [OE_OUTAGE_DATA](https://github.com/yaroslav2901/OE_OUTAGE_DATA):
`regionId`, `lastUpdated`, `fact.data`, `fact.update`, `fact.today`,
`preset.time_zone` та `preset.time_type`.
Код цього збирача власний; дані беруться з офіційного сайту, не зі старого дзеркала.
Додаткове поле `metadata` описує достовірність та статус кожного дня.

- `regionId`: `Poltava`.
- `lastUpdated`: UTC ISO 8601, остання успішна перевірка, записана у публікації.
- `fact.data`: ключ дня у вигляді Unix timestamp **опівночі Europe/Kyiv**.
  Не додавайте 86400 секунд для переходу між днями через літній/зимовий час.
- `fact.today`: сьогоднішня північ у Києві, навіть якщо є тільки графік на завтра.
- `fact.update`: локальний час останньої записаної перевірки, не час зміни на сайті.
- Групи: `GPV1.1` ... `GPV6.2`.
- Години: ключі `"1"` ... `"24"`; `"1"` відповідає 00:00–01:00.

| Код | Перші 30 хвилин | Другі 30 хвилин |
| --- | --- | --- |
| `yes` | Світло є | Світло є |
| `no` | Світла немає | Світла немає |
| `first` | Світла немає | Світло є |
| `second` | Світло є | Світла немає |
| `mfirst` | Жовтий, перемикання | Світло є |
| `msecond` | Світла немає | Жовтий, перемикання |

**Важливо:** для Полтаваобленерго `msecond` тут означає **червоний + жовтий**,
як і в попередньому дзеркалі, яке використовував наш бот. Не трактуйте його як
«зелений + жовтий» лише за назвою. Жовтий стан збережено окремо; у нашому боті
він не додається до запланованого часу повного відключення.
Якщо сайт запровадить комбінацію, якої немає у цій таблиці, збирач відмовиться
видавати її за іншу: файл залишиться попереднім до оновлення формату.

### Статус дня

`metadata.days["YYYY-MM-DD"]` містить:

- `status: "scheduled"`: отримано повну таблицю; вона може бути й повністю зеленою.
- `status: "no_outages"`: офіційний сайт явно повідомив, що відключення
  не прогнозуються. Для сумісності з простими старими клієнтами у `fact.data`
  записані всі години як `yes`.
- `status: "unknown"`: графік не отримано й підтвердженого кешу немає.
  У `fact.data` такого дня **немає**. Це не скасування відключень.
- `verifiedAt`: коли саме цей день востаннє підтверджено офіційним сайтом.
- `fresh`: чи підтверджено день у зборі даних, що сформував поточний файл.
  Це не обіцянка актуальності на момент вашого запиту: перевіряйте `verifiedAt`.

Простий Python-клієнт:

```python
import json
from urllib.request import urlopen

url = "https://raw.githubusercontent.com/findme88/poltava-outage-data/main/data/Poltavaoblenergo.json"
with urlopen(url, timeout=15) as response:
    payload = json.load(response)

today = str(payload["fact"]["today"])
schedule = payload["fact"]["data"].get(today, {}).get("GPV5.1")
print(schedule if schedule is not None else "Графік на сьогодні поки невідомий")
```

## Самостійний запуск

Python 3.11+ із базою часових зон IANA (стандартна Ubuntu вже має її).
На Windows за потреби встановіть `tzdata`.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -v
python collector.py
```

У публічному репозиторії немає Telegram-токенів, бази даних, імен або ID підписників.
Workflow використовує короткочасний стандартний `GITHUB_TOKEN` тільки для запису
в цей репозиторій, без персональних токенів чи доступу до приватного бота.
